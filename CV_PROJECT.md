**Technologies:** Java, Data Structures, Balanced Trees, Object-Oriented Programming

- Maintained dual indexes by stock ID and by price to support efficient lookup, update, and price-range retrieval workflows.
- Modeled timestamped price events per stock, including price updates and rollback by timestamp.
- Added validation and executable test scenarios for duplicates, invalid inputs, removed stocks, same-price stocks, and ordered range queries.
